# 사업 타당성 분석 기획절차서 (Playbook)

> 이 문서는 팀이 만든 사업 타당성 분석 모델(`market_model_case_student.xlsx`)의 구조를 일반화하고, 검토 과정에서 나온 개선사항을 더한 절차서입니다.
> 어떤 사업 아이디어든 **문제 정의 → 경쟁·포지셔닝 → 자료 → 가정 → 시장규모 → 단위경제 → 손익 → 기간별 현금흐름 → 민감도 → 판정 → 파일럿** 순서로 같은 틀을 적용할 수 있습니다.
> 각 단계는 **① 무엇을 구하는가 · ② 필요한 입력 · ③ 타당성 확인 방법**으로 구성됩니다.
> ✚ 표시는 예시 엑셀에는 없고 이 절차서에서 새로 추가한 내용입니다.

---

## 전체 흐름

```
0. 문제 정의 (판정 기준 先 확정)
      │
      ├─▶ 1. 경쟁 분석 ─▶ 2. 포지셔닝 ──┐   (선택 비율·차별점의 근거)
      │                                 ▼
      └─▶ 3. 자료 수집 ───────────▶ 4. 가정 설계
                                        │
                                        ▼
            5. 시장규모 ─▶ 6. 단위경제 ─▶ 7. 손익·손익분기 ─▶ 8. 규모별 손익(계단표)
                                        │
                                        ▼
                         9. 기간별 손익·현금흐름 ✚ ─▶ 10. 민감도 분석
                                                          │
                                                          ▼
                     11. 판정·보고서 ─▶ 12. 검토·심사 ─▶ 13. 파일럿 검증 ✚
                            ▲                                   │
                            └──────── 결과를 4단계 가정에 반영 ◀──┘
```

- **경쟁 분석을 숫자 모델보다 먼저** 합니다. 가장 근거가 약한 가정(우리 선택 비율, 차별점)의 근거가 경쟁 구도에서 나오기 때문입니다. 경쟁 분석(1~2단계)과 자료 수집(3단계)은 병행해도 됩니다.
- 계산은 **한 방향**으로만 흐릅니다. 앞 시트는 뒤 시트를 참조하지 않습니다.
- 입력값은 **자료** 시트와 **가정** 시트 두 곳에만 둡니다. 나머지 시트는 전부 수식입니다.
- 대안이 둘 이상이면(예: 운영 방식 A안/B안) 모든 계산 시트를 **대안 × 시나리오(보수/기준/낙관)** 열 구조로 만듭니다.

## 공통 규칙

| 구분 | 규칙 |
|---|---|
| 숫자 | 보고서의 모든 숫자는 엑셀 셀에서 가져온다. 엑셀에 없는 내용은 지어내지 않고 **[확인필요]**로 표시한다. |
| 자료 | 값 · 단위 · 기준 시점 · 출처 · URL을 함께 적는다. 못 찾으면 **'미확인'**으로 남긴다. |
| 가정 | 항상 **보수/기준/낙관** 세 값으로 제안하고, 근거를 한 줄 이상 적는다. |
| 구분 표시 | 모든 입력에 구분을 붙인다: **자료**(원문 확인) / **가정**(근거 약함, 검증 대상) / **설정**(사업 조건으로 정한 값) / **계산**. 보고서에서 '가정' 값을 쓸 때는 '가정'이라고 밝힌다. |
| 수식 | 계산은 반드시 수식으로 한다. 결과를 숫자로 써넣지 않는다. 자료 값을 쓰는 칸은 자료 시트 셀을 참조한다. 수식 안에 상수(예: 30일)를 박지 않고 입력 칸으로 뺀다. |
| 서식 | 파란 글씨 = 직접 입력, 초록 글씨 = 다른 시트 연결, 검정 = 계산. 바꿔도 되는 칸은 노란 배경. |
| 정직성 | 불리한 숫자를 빼거나 낙관 시나리오만 쓰지 않는다. |
| 비교 공정성 ✚ | 모든 대안에 같은 분석(민감도, 기간별 손익 등)을 똑같이 적용한다. |
| 결론 | **가 / 부 / 조건부 시행** 중 하나로 낸다. |

## 0단계. 문제 정의

**① 무엇을 구하는가**
- 이 분석이 답할 **의사결정 질문** 한 문장 (예: "○○ 지역에서 △△ 서비스를 시작할 것인가?")
- 비교할 **대안**(실행 방식 2~3개 + '하지 않음')
- **판정 기준** ✚: 무엇이 나오면 가 / 부 / 조건부 시행인지를 숫자를 보기 전에 정합니다. 결론에 맞춰 기준을 짜맞추는 것을 막기 위해서입니다.

**② 필요한 입력**
- 사업 범위: 대상 지역·고객·기간
- 회사가 이미 가진 자원: 고객 수, 점포·설비, 매입 조건, 브랜드, **기존 사업 매출**(잠식 검토용)
- 의사결정자가 정한 조건(설정값): 운영 시간, 투자 한도, **최대 감당 가능 누적 적자**, 목표 회수기간 등

**③ 타당성 확인**
- [ ] 질문이 '예/아니오'로 답할 수 있는 형태인가.
- [ ] 대안끼리 서로 겹치지 않고, 같은 기준으로 비교할 수 있는가.
- [ ] 판정 기준이 측정 가능한 숫자인가. 예:
  - 가: 기준 시나리오 월 영업이익 > 0, 그리고 회수기간 ≤ ○년, 그리고 보수 시나리오 누적 적자 최대치 ≤ 감당 한도
  - 조건부 시행: 기준 시나리오는 기준을 충족하지만 핵심 가정이 '가정' 단계인 경우 → 파일럿으로 검증
  - 부: 기준 시나리오가 손익분기 '도달 불가'이거나, 누적 적자가 한도를 넘는 경우

## 1단계. 경쟁 분석 (`경쟁비교` 시트)

**① 무엇을 구하는가**
- 고객이 우리 대신 선택할 수 있는 모든 대안의 비교표. 대안은 다섯 층으로 봅니다:
  **직접 경쟁 · 간접 경쟁 · 대체재 · 현상 유지(구매 미루기) · 우리**
- 비교 항목: 대상 고객, 핵심 가치, 가격·수익 방식, 채널, 강점/약점, 근거
- 4단계 가정의 근거: **우리 선택 비율**(경쟁자 수와 선점 정도), 가격·고객 부담 수수료 수준

**② 필요한 입력**
- 경쟁사 공시·보도·앱/웹 화면, 고객 조사

**③ 타당성 확인**
- [ ] 모든 칸에 태그가 있는가: **[F]** 확인한 사실 · **[I]** 해석 · **[U]** 미확인.
- [ ] [F] 칸에는 출처가 있는가.
- [ ] '현상 유지'와 '대체재'를 빠뜨리지 않았는가. 대부분의 신사업은 경쟁사가 아니라 '안 사는 것'과 경쟁한다.
- [ ] 우리 행의 강점이 [I]뿐이라면 그 사실을 보고서에 밝혔는가.

---

## 2단계. 포지셔닝 (`포지셔닝` 시트)

**① 무엇을 구하는가**
1. **축 후보 채점**: 축 쌍 2~3개를 세 조건(각 1~5점)으로 채점
   - 고객이 실제로 보는 기준인가 / 두 축이 서로 독립인가 / 근거로 위치를 정할 수 있는가
2. **점수표**: 선택된 축에서 각 대안의 점수(1~5)와 태그, 근거 셀
3. **포지셔닝 맵**(산점도)
4. **빈 자리 해석**: 영역별로 누가 있는지, 왜 비었는지, 판정(기회 / 레드오션 / 함정 가능성)

**② 필요한 입력**
- 1단계 비교표(점수 근거는 비교표 셀을 가리켜야 함)

**③ 타당성 확인**
- [ ] 점수를 표에서 먼저 확정한 뒤 그림을 그렸는가(그림에 맞춰 점수를 조정하지 않는다).
- [ ] **점검 질문**: 우리 점을 지워도 축이 경쟁자들을 의미 있게 가르는가.
- [ ] 우리와 같은 점수인 경쟁자 수를 셌는가(`COUNTIF`). 많으면 그 축으로는 차별되지 않는다.
- [ ] '빈 자리'마다 **수요가 없어서 빈 것(함정)**인지 검토하고, 13단계 파일럿에서 확인할 지표를 적었는가.

## 3단계. 자료 수집 (`자료` 시트)

**① 무엇을 구하는가**
- 모델에 들어갈 **외부에서 확인 가능한 숫자** 전부. 대표 항목:

| 범주 | 예시 항목 |
|---|---|
| 수요 기반 | 대상 지역 인구·세대·사업체 수, 전국 합계(비중 계산용) |
| 시장 | 산업 시장 규모, 이용률·침투율(과거 값 포함), 1회 지출액 |
| 벤치마크 | 선도 사업자의 매출·주문 수·거점 수(객단가·거점당 매출 역산용) |
| 고객 획득·유지 ✚ | 업계 평균 고객 획득비용, 재구매율·이탈률, 앱 설치 대비 구매 전환율 |
| 비용 | 최저임금·인건비 요율, 임대료, 수수료율, 외주 단가, 부자재 가격 |
| 거시 | 물가지수(과거 값을 현재 가치로 보정할 때) |

**② 필요한 입력**
- 공공 통계(통계청·행정기관), 공시(DART 등 감사보고서), 조사기관 리포트, 언론 보도, 견적·구인공고

**③ 타당성 확인**
- [ ] 모든 행에 값 · 단위 · 기준 시점 · 출처 · URL이 있는가. 비었으면 '미확인'인가.
- [ ] 합계는 원자료 셀의 `SUM`으로 계산했는가(예: 지역 세대 수 = 하위 행정구역 합계).
- [ ] **정의 차이**를 비고에 적었는가: 개인 vs 세대, 전국 vs 지역, 연결 vs 단독, 설문값 vs 실적값.
- [ ] **기준 시점 차이**를 처리했는가. 오래된 값은 물가지수 등으로 보정하고, 보정 과정을 별도 칸으로 보이게 한 뒤 '추정'이라고 표시한다.
- [ ] 신뢰도가 낮은 값(공고 1건, 기사 '약 ○억')은 비고에 교체 계획을 적었는가.
- [ ] 같은 항목에 출처가 여러 개면 범위를 함께 적었는가(기관별 편차).

## 4단계. 가정 설계 (`가정` 시트)

**① 무엇을 구하는가**
- 모든 입력 변수의 **보수 / 기준 / 낙관** 세 값과 구분·근거
- 모델의 유일한 조작판입니다. 이 시트만 바꾸면 전체가 다시 계산되어야 합니다.

**② 필요한 입력**
- 1~2단계 경쟁·포지셔닝 결과(선택 비율·가격의 근거)
- 3단계 자료(연결해서 사용)
- 내부 데이터, 업계 관행, 전문가 의견
- 아래 범주별 변수:

| 범주 | 변수 예시 |
|---|---|
| ① 수요 | 대상 수, 이용률, 우리 선택 비율(점유율), 구매 빈도, 객단가 |
| ①-2 고객 획득·유지 ✚ | 고객 획득비용(신규 고객 1명당 마케팅비), 월 재구매율(유지율), 목표 고객 수 도달 기간(램프업 개월 수) |
| ①-3 기존 사업 잠식 ✚ | 새 매출 중 기존 채널·점포에서 옮겨온 비율(잠식률), 기존 채널의 공헌이익률 |
| ② 건당 변동비 | 매출총이익률, 할인·프로모션율, 결제 수수료율, 배송·물류비, 고객 부담 수수료, 포장·부자재, 폐기·감모율, 세금 순부담 |
| ③ 인건비·생산성 | 시급, 법정 가산(주휴 등), 사업주 부담률, 운영 시간, 시간당 처리량, 가동률, 최소 인원 |
| ④ 고정비(대안별) | 임차·관리비, 관리자 급여, 에너지, 시스템, 감가상각(투자 ÷ 연수 ÷ 12), 마케팅, 기타 |
| ⑤ 투자·운전자본 ✚ | 초기 투자(설비·인테리어·보증금), 개업 전 비용, 재고 운전자본 |
| ⑥ 공통 상수 ✚ | 월 영업일 수, 분석 기간(개월) 등 수식에 들어가는 상수 |
| ⑦ 교차 확인용 | 기존 회원 수, 기존 매출 등 |

**③ 타당성 확인**
- [ ] 모든 변수에 세 값이 있는가. 값이 하나뿐이면 '설정'이나 '자료'로 구분했는가.
- [ ] 세 값의 방향이 맞는가. 비용 항목은 보수 쪽이 더 높아야 한다(예: 폐기율 보수 > 기준 > 낙관).
- [ ] 보수~낙관 **범위의 폭이 근거 수준을 반영**하는가 ✚. 근거가 약한 가정일수록 범위를 넓게 잡는다. 이 범위가 10단계 민감도의 입력이 된다.
- [ ] 구분이 '가정'인 항목 중 **근거가 가장 약한 것**을 표시했는가. 보통 '우리 선택 비율'이 여기에 해당하며, 13단계 파일럿에서 먼저 검증할 대상이다.
- [ ] 자료가 있는 변수는 숫자로 직접 쓰지 않고 자료 시트에 연결했는가.
- [ ] 계산 변수(예: 시간당 실부담 인건비 = 시급 × (1+가산) × (1+부담률))도 수식인가.
- [ ] 단위가 일관된가(%, 원, 건, 시간 / 월 vs 연).
- [ ] 마케팅비가 고객 획득비용 × 신규 고객 수와 맞물리는가 ✚. 마케팅비와 선택 비율을 따로 정하면 둘 중 하나는 근거가 없다.
- [ ] 기존 사업이 있는 회사라면 잠식률을 0으로 두지 않았는가 ✚. 0이라면 그 근거를 적었는가.

## 5단계. 시장규모 (`시장규모` 시트)

**① 무엇을 구하는가**
- **하향식**: TAM(전체 시장) → SAM(우리 지역·대상으로 좁힌 시장)
- **상향식**: SOM(우리가 실제로 얻을 매출) = 대상 수 × 이용률 × 선택 비율 × 빈도 × 객단가
- **증분 매출** ✚ = SOM × (1 − 잠식률). 회사 전체에 새로 생기는 매출
- 상향식 결과에서 **정상 궤도의 월 주문 수·일 주문 수**를 구해 이후 단계의 입력으로 씁니다.

**② 필요한 입력**
- TAM과 비중 기준(예: 지역 세대 ÷ 전국 세대): 3단계
- 수요·잠식 변수 세 시나리오: 4단계

**③ 타당성 확인 — 여러 방법으로 교차 확인**

| 확인 | 계산 | 읽는 법 |
|---|---|---|
| 상향식 ÷ 하향식 | SOM ÷ SAM | 가정한 선택 비율과 비슷한 크기여야 정상. 크게 다르면 어느 한쪽 가정이 틀린 것 |
| 유사 사례 대비 | 우리 월 매출 ÷ 선도 사업자 거점(점포) 1곳 평균 월 매출 | 1위 사업자 평균은 상한선. 100%를 넘으면 가정 오류 |
| 기존 고객 대비 | 월 구매 고객 ÷ 기존 회원 수 | "회원 몇 명 중 한 명이 매달 사야 하는가"가 현실적인가 |
| 객단가 검증 | 벤치마크 매출 ÷ 주문 수 (필요하면 물가 보정) | 설문 객단가가 과대평가됐는지 확인 |
| 도달 가능성 ✚ | 월 신규 고객 × 재구매율 누적 (9단계) | 상향식 고객 수에 램프업 기간 안에 도달할 수 있는가 |

- [ ] 하향식에서 지역별 이용 강도 차이를 무시했다면 그 한계를 적었는가.
- [ ] 판정에 쓰는 매출이 SOM이 아니라 **증분 매출**인가 ✚.

## 6단계. 단위경제 (`단위경제` 시트)

**① 무엇을 구하는가**
- **주문(판매) 1건에서 남는 돈** = 공헌이익
  - 처리 인건비 차감 **전** 공헌이익: 순수 변동비만 뺀 값
  - 처리 인건비 차감 **후** 공헌이익: 완전 가동 기준 건당 인건비까지 뺀 값
  - 공헌이익률 = 공헌이익 ÷ 객단가
- **고객 단위 경제** ✚: 고객 1명의 평생 공헌이익(LTV) = 건당 공헌이익 × 월 주문 횟수 × 평균 유지 개월 수(= 1 ÷ (1 − 월 재구매율)), 그리고 **LTV ÷ 고객 획득비용**

```
객단가
× 매출총이익률              = 매출총이익
− 할인·프로모션 (객단가 × 율)
− 폐기·감모 (객단가 × 율, 대안별로 다름)
− 결제 수수료 (객단가 × 율)
− 순 배송비 (배송 원가 − 고객 부담분)
− 포장·부자재
− 세금 순부담 (예: 부가세)
= 처리 인건비 차감 전 공헌이익
− 건당 처리 인건비 = 시간당 인건비 ÷ (시간당 처리량 × 가동률)
= 처리 인건비 차감 후 공헌이익
− 잠식된 기존 매출의 공헌이익 ✚ (잠식률 × 기존 채널 건당 공헌이익)
= 증분 공헌이익 ✚
```

**② 필요한 입력**
- 4단계의 ①-2, ①-3, ②, ③ 범주 변수

**③ 타당성 확인**
- [ ] **빠뜨리기 쉬운 항목**을 넣었는가: 세금 순부담, 결제 수수료, 폐기, 고객 부담분 차감, 잠식분 ✚.
- [ ] 대안별로 달라지는 항목(폐기율, 처리 속도, 가동률)을 대안 열마다 다르게 참조했는가.
- [ ] 보수 시나리오 공헌이익이 0 이하라면 그 사실을 숨기지 않았는가. 이 경우 손익분기는 '도달 불가'다.
- [ ] 건당 인건비는 '완전 가동' 가정임을 명시했는가. 실제 인건비는 7~8단계 계단식 계산으로 확인한다.
- [ ] LTV ÷ 고객 획득비용이 1보다 큰가 ✚. 1 이하면 고객을 얻을수록 손해다(업계에서는 보통 3 이상을 건전한 수준으로 본다).

## 7단계. 손익·손익분기 (`손익` 시트)

**① 무엇을 구하는가**
- 정상 궤도의 월·연 영업손익, 영업이익률
- 필요 인원 = MAX(최소 인원, 올림(일 처리량 ÷ 1인 하루 처리 능력)) → **계단식 인건비**
- 손익분기 일 주문 수 = 월 고정비 ÷ 건당 공헌이익(처리 인건비 차감 후) ÷ 월 영업일 수
- 현재 주문 ÷ 손익분기 주문 (1 이상이면 흑자 구간)

**② 필요한 입력**
- 주문 수: 5단계 / 건당 공헌이익: 6단계 / 인력·고정비: 4단계 ③·④

**③ 타당성 확인**
- [ ] 영업손익 = 공헌이익 합계 − 처리 인건비 − 고정비가 맞는가.
- [ ] 공헌이익이 0 이하면 손익분기를 `IF`로 '도달 불가' 처리했는가(음수 손익분기 방지).
- [ ] 대안별 고정비 구성이 다르다면(예: 전용 시설 vs 기존 시설 공유) 각각 무엇이 들어갔는지 적었는가.
- [ ] 감가상각 = 초기 투자 ÷ 상각 연수 ÷ 12 로 반영했는가.
- [ ] 이 단계 결과는 '정상 궤도에 오른 어느 달'의 손익임을 명시했는가. 그 달에 도달하기까지의 비용은 9단계에서 본다.

---

## 8단계. 규모별 손익 (`계단표` 시트)

**① 무엇을 구하는가**
- 일 주문 수를 여러 수준(예: 50 → 1,500건)으로 바꿨을 때 대안별 **필요 인원과 월 손익**
- 인원이 계단식으로 늘어나기 때문에 '고정비 ÷ 공헌이익' 공식만으로는 정확한 손익분기가 나오지 않습니다. 이 표로 **실제 흑자 전환 구간**을 확인합니다.

**② 필요한 입력**
- 주문 수 구간(직접 입력, 바꿔도 되는 칸), 6·7단계 결과

**③ 타당성 확인**
- [ ] 7단계 손익분기 값 근처에서 손익 부호가 바뀌는가. 차이가 나면 계단식 인건비 때문인지 확인한다.
- [ ] 주문이 늘었는데 이익이 줄어드는 구간(인원 1명 추가 직후)이 있는지 보고, 있으면 운영 시사점을 적는다.
- [ ] 대안 간 **역전 구간**(A안이 B안보다 나아지는 규모)이 있으면 표시한다.

---

## 9단계. 기간별 손익·현금흐름 ✚ (`기간별` 시트)

**① 무엇을 구하는가**
- 개업부터 12~36개월까지 **월별** 손익과 현금흐름
  - 월 고객 수 = 전월 고객 × 재구매율 + 월 신규 고객 (신규 고객 = 마케팅비 ÷ 고객 획득비용)
  - 월 주문 수 → 월 공헌이익 → 계단식 인건비 → 고정비 → 월 영업손익
  - 월 현금흐름 = 영업손익 + 감가상각(비현금) − 투자 − 운전자본 증가
- 핵심 산출값:
  - **월 흑자 전환 시점**(몇 개월 차)
  - **누적 적자 최대치**(가장 깊은 현금 바닥) = 실제로 필요한 자금
  - **투자 회수기간**(누적 현금흐름이 0을 넘는 시점)
  - (선택) 할인율을 적용한 순현재가치(NPV)

**② 필요한 입력**
- 4단계 ①-2(고객 획득비용·재구매율·램프업), ⑤(투자·운전자본), 6~7단계 건당 공헌이익·인력 로직

**③ 타당성 확인**
- [ ] 마지막 달(정상 궤도)의 손익이 7단계 손익 시트의 결과와 일치하는가.
- [ ] 고객 수가 5단계 상향식 고객 수를 넘지 않는가(시장 상한).
- [ ] 누적 적자 최대치가 0단계에서 정한 감당 한도 안에 있는가. **보수 시나리오로도** 확인한다.
- [ ] 초기 투자가 큰 대안과 작은 대안을 같은 기간으로 비교했는가. 월 손익만 보면 투자가 큰 대안이 유리해 보일 수 있다.
- [ ] 감가상각을 손익에서는 비용으로, 현금흐름에서는 다시 더했는가(투자를 이중으로 빼지 않기).

---

## 10단계. 민감도 분석 (`민감도` 시트)

**① 무엇을 구하는가**
- 기준 시나리오에서 **가정 하나만** 바꿨을 때 월 손익(그리고 9단계의 누적 적자 최대치·회수기간)
- 바꾸는 폭은 일괄 ±20% 대신 **각 가정의 보수~낙관 범위** ✚를 씁니다. 근거가 약한 가정은 범위가 넓으므로 영향이 제대로 드러납니다(토네이도 차트).
- 변화 폭이 큰 순서 = **결과를 좌우하는 가정 순위**
- (선택) 상위 두 가정을 동시에 바꾸는 2차원 표 ✚. 예: 선택 비율 × 객단가에서 흑자가 되는 조합

**② 필요한 입력**
- 4단계의 주요 변수와 보수/낙관 값, 6~9단계 계산 로직

**③ 타당성 확인**
- [ ] '기준' 행 결과가 손익 시트의 기준 시나리오 결과와 정확히 같은가(로직 일치 검증).
- [ ] **모든 대안**에 대해 수행했는가 ✚. 한 대안만 분석하면 비교가 공정하지 않다.
- [ ] 변화 폭 상위 가정의 근거 수준을 확인했는가. **영향이 크고 근거가 약한 가정**이 13단계 파일럿의 1순위 검증 대상이다.
- [ ] 결과의 부호(흑자/적자)를 바꾸는 가정이 있으면 보고서에 명시했는가.
- [ ] 일괄 ±20%를 함께 보여준다면, 같은 폭이 가정마다 현실성이 다르다는 점을 적었는가.

---

## 11단계. 판정·보고서

**① 무엇을 구하는가**
- 결론: **가 / 부 / 조건부 시행** 중 하나
- 조건부라면 **측정 가능한 조건**과 기한, 그리고 13단계 파일럿 설계
- 권장 대안(A안/B안 등)과 그 이유

**② 필요한 입력**
- 0단계 판정 기준, 7~10단계 숫자(모든 시나리오·모든 대안), 1~2단계 차별점 판단

**③ 타당성 확인**
- [ ] 보고서의 모든 숫자에 대응하는 엑셀 셀이 있는가.
- [ ] 구분이 '가정'인 값을 쓴 문장에 '가정'이라고 적었는가.
- [ ] 엑셀에 없는 주장에는 [확인필요]를 붙였는가.
- [ ] 보수 시나리오, 적자, '도달 불가', 누적 적자 최대치, 민감도 하락 폭을 함께 제시했는가.
- [ ] 결론이 0단계에서 정한 판정 기준과 맞는가. 맞지 않는다면 그 이유를 설명했는가.
- [ ] 판정이 SOM이 아닌 **증분 이익** 기준인가 ✚.

---

## 12단계. 검토·심사

**① 무엇을 구하는가**
- 보고서와 모델에 대한 독립 검토 의견과 판정이 타당한지

**② 필요한 입력**
- 완성된 엑셀과 보고서 초안

**③ 타당성 확인 — 모델 점검 체크리스트**

| 점검 | 방법 |
|---|---|
| 오류값 | `#REF!`, `#DIV/0!`, `#VALUE!` 등이 없는가 |
| 숫자 직접 입력 | 계산 시트에 수식이 아닌 숫자가 없는가. 가정 시트의 자료 항목이 자료 시트에 연결돼 있는가 |
| 텍스트 숫자 | 숫자가 텍스트로 저장된 칸이 없는가 |
| 단일 입력 원칙 | 같은 값이 두 곳에 따로 입력되어 있지 않은가 |
| 상수 숨김 | 수식 안에 상수(예: 30일, 과거 실적값)가 박혀 있다면 입력 칸으로 뺐는가 |
| 라벨 일치 | 항목 이름과 수식 결과가 같은 것을 가리키는가 |
| 시트 간 일치 | 민감도 '기준' = 손익 '기준', 계단표 손익분기 ≈ 손익 손익분기, 기간별 마지막 달 = 손익 정상 궤도 |
| 극단값 테스트 | 수요 0, 객단가 0 등을 넣었을 때 오류 없이 '도달 불가' 등으로 처리되는가 |
| 비교 공정성 ✚ | 모든 대안에 같은 분석을 적용했는가 |

## 13단계. 파일럿 검증 ✚ (조건부 시행일 때)

**① 무엇을 구하는가**
- 근거가 약한 핵심 가정을 **작은 규모로 실제 확인**하는 실험 설계와 그 결과
  - 검증할 가정(10단계 상위 + 구분이 '가정'인 항목)
  - 측정 지표와 목표값(예: 선택 비율, 재구매율, 객단가, 시간당 처리량)
  - 기간과 규모(예: 3개월, 일부 지역·일부 고객)
  - **중단 기준**: 이 숫자 아래면 접는다
  - **확대 기준**: 이 숫자 위면 본 사업으로 간다

**② 필요한 입력**
- 10단계 민감도 순위, 4단계 가정의 보수/기준 값, 2단계의 '함정 가능성' 영역

**③ 타당성 확인**
- [ ] 중단·확대 기준을 파일럿 **시작 전에** 정했는가.
- [ ] 측정 지표가 엑셀의 특정 가정 셀과 1:1로 대응하는가.
- [ ] 파일럿 비용과 기간이 0단계 감당 한도 안인가.
- [ ] 결과를 **4단계 가정 시트에 반영**(구분을 '가정' → '자료'로 바꾸고 출처에 파일럿 기록)하고, 5~11단계를 다시 돌려 판정을 갱신했는가.

| 7 | 기간별 ✚ | 계산 | 월별 손익·현금흐름, 흑자 전환 시점, 누적 적자 최대치, 회수기간 |
| 8 | 민감도 | 계산 | 가정별 보수~낙관 범위 영향, 순위, 2차원 표 ✚ (모든 대안) |
| 9 | 경쟁비교 | 정성 | 대안 다섯 층 비교표 ([F]/[I]/[U]) |
| 10 | 포지셔닝 | 정성+계산 | 축 채점, 점수표, 맵, 빈 자리 해석 |
| 11 | 파일럿 ✚ | 입력+기록 | 검증 가정, 지표, 중단·확대 기준, 결과 |

※ 작업 순서는 경쟁비교·포지셔닝이 먼저이지만, 시트 배치는 조작판(가정)을 맨 앞에 두는 편이 쓰기 편합니다.
