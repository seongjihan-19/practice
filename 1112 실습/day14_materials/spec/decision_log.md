## 결정 상세

### D-01 · 11/16 MVP 기준 시안
- **질문:** 모바일 웹 시안이 두 개 있는데, 11/16 MVP는 어느 쪽을 기준으로 할까?
- **선택지:** index.html (목록형) / index_v2.html (배치도형) / 둘을 섞기
- **결정:** index.html (목록형)
- **근거 메모:** ideas_top3.md가 MVP를 "화면 하나(매대 카드 목록)"로 적고 있음. v2의 매대 위치(입구 쪽 · 가운데 · 안쪽)는 지어낸 값임(no-request.md #5).
- **영향:** index_v2.html은 참고 시안으로만 남는다.

### D-02 · US-1 우선순위
- **질문:** US-1(퇴근 전 오늘 야시장 · 매대 영업 여부 확인)을 어떻게 둘까?
- **선택지:** 나중 유지 / 필수로 올림
- **결정:** 나중 유지
- **근거 메모:** 운영 공지(D2)는 미보유이고 상인회와 협의 전임(bm_canvas.md 10). 매대별 오늘 영업 여부는 US-2에서 계속 보여 준다.

### D-03 · 장사 중 품절 입력
- **질문:** 장사 중에 생긴 품절을 상인이 입력하는 기능은 언제 넣을까?
- **선택지:** 보류 유지 / MVP에 포함
- **결정:** 보류 유지 — 11/16 MVP 뒤에 다시 본다.
- **영향:** MVP는 장사 전 입력 기준의 품절과 기준 시각("상인 입력 hh:mm")만 표시한다. 시나리오.md US-3의 예외 "장사 중 생긴 품절"이 그대로 유효하다.

### D-04 · 결제 수단을 여러 개 골랐을 때 판정
- **질문:** 방문객이 결제 수단을 여러 개 고르면, 어떤 매대를 '살 수 있음'으로 볼까?
- **선택지:** 하나라도 되면(OR) / 한 개만 고르기
- **결정:** 하나라도 되면(OR)
- **영향:** 시나리오.md US-2 인수조건 2를 "고른 수단 중 하나라도 되는 오늘 영업 매대"로 읽는다. 고른 수단이 모두 '정보 없음'인 매대는 '살 수 있음'에 넣지 않는다(US-2 예외).

### D-05 · AI 표시 문구
- **질문:** 매대 카드의 AI 표시 문구를 어떻게 할까?
- **선택지:** 재료 문구 그대로 / 확인 문구 덧붙임("· 상인 확인 후 게시")
- **결정:** 재료 문구 그대로 — "AI 정리 · 상인 입력 hh:mm 기준"
- **근거 메모:** ideas_top3.md · bm_canvas.md 11의 문구를 따른다.
- **영향:** index_v2.html의 덧붙인 문구는 이 결정과 다르다. 다만 D-01로 v2는 참고 시안이다.

### D-06 · 야시장 전체 운영 상태 영역
- **질문:** 화면 맨 위의 운영 상태('오늘 영업 · 18:00 개장')는 지금 매일 연다고 가정하고 보여 준다. 운영 공지가 없는 동안 어떻게 할까?
- **선택지:** 영역을 빼기 / '정보 없음'으로 표시 / 가정 그대로 둠
- **결정:** 영역을 뺀다.
- **근거 메모:** 근거 없는 "오늘 영업"을 보여 주지 않는다. US-1 '나중'(D-02)과 맞춘 결정이다.
- **영향:** index.html의 상단 야시장 상태 영역(18:00–23:00 데모 값)을 MVP에서 빼야 한다. 매대별 오늘 영업 여부는 유지한다.

### D-07 · 시나리오 주인공의 결제 수단
- **질문:** 시나리오 주인공(현금 없는 대구 직장인)이 가진 결제 수단을 무엇으로 정할까?
- **선택지:** 카드 · 간편결제 / 카드만 / 확인 필요 유지
- **결정:** 카드 · 간편결제
- **성격:** 자료에서 확인된 사실이 아니라 **팀 결정(가정)** 이다.
- **영향:** 시나리오.md 0. 상황의 "가진 결제 수단: 확인 필요"를 "카드 · 간편결제 (팀 결정 · 가정)"로 바꿀 수 있다.

### D-08 · 계좌번호를 소리 내어 알려 주는 문제(r_055)
- **질문:** 계좌이체 때 상인이 계좌번호를 큰 소리로 불러 주는 문제(VOC r_055)를 이번 범위에서 어떻게 다룰까?
- **선택지:** 범위 밖 / 후보 목록에 추가
- **결정:** 범위 밖
- **근거 메모:** 1위 아이디어는 정보 표시만 다룬다. 매대판에 계좌번호를 싣지 않는 것(bm_canvas.md 11 가림 처리)으로 끝낸다.
- **영향:** 시나리오.md 확인 필요 #9를 "범위 밖(D-08)"으로 닫을 수 있다.
