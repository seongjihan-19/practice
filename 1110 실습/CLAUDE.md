# CLAUDE.md — 1110 실습 (VOC 페인포인트 태깅)

수업 예시용 가상 데이터로, 서문시장 야시장 식품 구매자의 VOC 300건을 페인포인트 정의서 기준으로 태깅한다.

## 폴더 구조
- `painpoint/painpoint_def.md` — 페인포인트 정의서 (P1~P3, 보류 H1~H2, 분류 규칙). **태깅의 유일한 기준.**
- `archive/batch1~3/r_XXX.md` — VOC 원문 (배치당 100건, frontmatter: voc_id · source · date)
- `archive/metadata.csv` — voc_id, source, date, file 목록
- `ax/demo/parts/part_N.csv` — 태깅 결과 (N = 묶음 번호, batchN에 대응)
- `ax/demo/scores/score_N.md` — 채점 점수표
- `.claude/agents/review-tagger.md` — 분류 담당 / `review-grader.md` — 채점 담당
- `*.pdf` — 참고 자료 (태깅 작업과 무관)

## 작업 규칙
- `archive/`와 `painpoint/`는 **읽기 전용**. 원문 · 정의서를 수정하지 않는다.
- 태깅은 `review-tagger`에 묶음 단위로 맡긴다 (묶음 3개는 서로 독립, 병렬 가능). 10건씩 읽을 때마다 즉시 저장한다.
- 태깅이 끝난 묶음은 `review-grader`로 채점한다. 채점관은 태그를 고치지 않는다.
- 허용 태그: `P1` · `P2` · `P3` · `H1` · `H2` · `해당없음` · `검토` — 이 외의 태그를 만들지 않는다.
- 근거 인용은 원문 그대로, 15자 이내. 의역 · 요약 금지. 원문에 없는 내용은 지어내지 않는다.
- 정의서에 없는 새 페인포인트로 보이는 글은 `검토`로 두고 note에 적는다. 정의서를 임의로 바꾸지 않는다.

## 출력 형식 (`ax/demo/parts/part_N.csv`, UTF-8)
```
voc_id,tag,evidence,note
r_001,P1,현금 5천 원 들고 갔다가,
r_002,해당없음,다들 만족,
```
- 한 VOC당 한 행. 묶음의 100건이 모두 있어야 한다.
- `evidence`는 **모든 행에 필수** (`해당없음` 포함).
- `note`는 `검토`일 때만 이유를 적고, 그 외에는 비워 둔다.

## 검증 기준 (완료 조건)

| # | 검증 항목 | 확인 내용 | 채점 항목 | 통과 조건 | 관제 화면 표시 |
|---|---|---|---|---|---|
| 1 | voc_id 누락 · 중복 | VOC 파일을 읽을 때 `archive/metadata.csv` 기준으로 voc_id 누락 · 중복이 없는지 확인 | 채점관 **범위 점수** | 누락 0건 · 중복 0건 | — |
| 2 | 원문 인용 근거 | 모든 행에 원문 인용 근거(`quote`)가 있는지 확인 | 채점관 **근거 점수** | 모든 행에 근거 있음 | — |
| 3 | 태그 허용 목록 | 태그가 허용 목록 7개(P1 · P2 · P3 · H1 · H2 · 해당없음 · 검토) 안에만 있는지 확인 | 채점관 **형식 점수** | 목록 밖 태그 0건 | — |
| 4 | 검토 태그 비율 · 이유 | `검토` 태그 비율과 note(이유) 기재 여부 확인 | — | 전체의 **5% 이하** · 모든 `검토` 행에 이유 기재 | **검토 건수** 표시 |
| 5 | 채점 세 묶음 | 범위 · 근거 · 형식 세 묶음의 채점 결과 | 범위 · 근거 · 형식 | 세 묶음 **모두 80점 이상** | **채점 패널** 표시 |
| 6 | 사람 대조 · 승인 | 사용자가 표본 10건을 직접 대조 | 사용자 대조 | 10건 중 **9건 이상 동의** · **최종 승인은 사용자만** | — |

- 1~5번을 모두 통과해야 6번(사용자 대조)으로 넘어간다.
- Claude는 승인을 대신하지 않는다. 사용자 승인 전에는 결과를 "완료"로 보고하지 않는다.

## 집계
세 배치가 끝나면 태그별 건수와 `검토` 목록을 요약해 사용자에게 보고한다. 측정 신호(정의서의 "측정 신호")와 연결해 P1~P3 순위가 VOC와 맞는지 한 줄로 코멘트한다.
